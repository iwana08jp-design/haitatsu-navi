# 配達ナビ（個人用）

iPhone のホーム画面に置いて使う、オフライン対応の配達ルートナビです。

- 地図：国土地理院タイル（ダウンロードして端末に保存）
- 道路データ：OpenStreetMap（Overpass API から取得し、端末内で経路計算用に変換）
- 住所検索：オンライン時は国土地理院の住所検索（番地まで）、オフライン時は同梱の町名データ（Geolonia 住所データ）
- 経路計算・順番の最適化：端末内（Web Worker）で計算。通信不要

## 公開のしかた
このフォルダ一式を HTTPS のサイト（GitHub Pages など）に置きます。
iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」。

## 地図の種類を増やす（ゼンリン契約後）
`js/app.js` の `MAP_SOURCES` に、契約で案内されるタイルのURLと著作権表示を追加します。
オフライン保存が契約で認められているかは、契約内容を確認してください。
